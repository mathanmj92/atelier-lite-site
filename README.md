# Atelier Lite: website

The landing page for [Atelier Lite](https://github.com/mathanmj92/atelier-lite): a Windows desktop suite with a word processor, slides, a spreadsheet and a PDF editor, plus one AI assistant.

A static page: `index.html`, `styles.css`, `script.js` and `assets/`. No build step. Publish it with GitHub Pages (branch `main`, folder `/`).

The Download button points at the latest GitHub release of the app repository.
